# A股智研台离线评测报告

## 1. 目的与复现方式

离线评测验证检索、技术指标、数据质量、AI grounding、AI 缓存复用和异常安全降级。默认模式只使用固定 JSON、合成静态行情与进程内 fake，不访问 Tushare、DeepSeek 或其他网络服务，也不消耗积分/额度。

```bash
.venv/bin/python scripts/evaluate.py
```

机器可读报告写入被 Git 忽略的 `artifacts/evaluation-report.json`。脚本在任一强制门槛未达标时返回非零退出码。`--live` 是显式可选的配置就绪检查，只输出“是否配置”和非敏感模型名，绝不打印 Token 或 API Key；发布前真实 API smoke test 由单独的发布验收执行。

## 2. 数据集与版本

| 子集 | 固定规模 | 内容 |
|---|---:|---|
| 搜索标注 | 100 个查询 | 25 只股票，每只覆盖完整 `ts_code`、六位代码、全名与名称片段；期望代码人工固定在 `search-cases-v1` |
| 静态行情 | 500 行 | 上涨、下跌、横盘、高波动、跳空/放量五种模式，各 100 行 |
| 数据质量 | 10 案例 | 缺列、缺值、乱序、重复日、非正价格、负成交量、OHLC 非法、空行情、59 日预热、空展示区间 |
| AI grounding | 50 案例 | 25 个合法引用与 25 个伪造 key/数值/观察位/多余字段案例 |
| 缓存 | 10 案例 | 一次暖缓存后相同键重复读取，验证模型调用被跳过 |
| 异常矩阵 | 25 案例 | 10 个数据质量、7 个 Tushare、6 个 DeepSeek、2 个缓存异常 |

JSON 标注位于：

- `tests/evaluation/search_cases.json`
- `tests/evaluation/error_cases.json`

|---|---:|---:|---|
| 搜索 Top-5 命中率 | 100 | ≥ 95% | 非零退出 |
| 指标参考一致率 | 500 行 | 100% | 非零退出 |
| 数据质量检测率 | 10 | 100% | 非零退出 |
| AI grounding 判定率 | 50 | 100% | 非零退出 |
| 缓存跳过率 | 10 | 100% | 非零退出 |

本表是冻结验收契约；具体运行值、失败案例和时间以当次 `artifacts/evaluation-report.json` 为唯一机器证据。课程统一验收应同时运行 `tests/test_evaluation.py`，验证分母、披露字段、文档顺序与 `--live` 输出不泄密。

## 4. 数值参考实现

- 被测公式版本：`indicators-v1`。
- 评分规则披露版本：`score-v1`。
- 独立参考公式版本：`evaluation-reference-v1`。
- 行级比较容差：`rtol = 1e-6`、`atol = 1e-8`，缺失值按同位置 NaN 一致处理。
- 比较字段覆盖 MA5/10/20/60、EMA12/26、MACD/Signal/Histogram、布林带、RSI14、KDJ、TR/ATR14、OBV、成交量均线/比率和 5/10/20 日收益。

参考实现独立转写冻结公式，使用不同的均线表达（滚动和除以窗口）与显式 KDJ 递推来降低“拿实现和自身比较”的风险。五类行情各行整体一致才计为正确；任一字段超容差，该行即失败并在 JSON 报告中记录差异字段。

## 5. 完整异常矩阵

### 5.1 数据质量（10）

必要字段缺失、必要值缺失、日期乱序、重复交易日、价格非正、成交量为负、OHLC 关系非法、空行情、预热仅 59 日、展示区间为空。期望行为均为 `valid=false` 且提供非空、可操作的质量 warning，不继续输出误导评分。

### 5.2 Tushare（7）

| 场景 | 安全结果 |
|---|---|
| 未配置 Token | `CONFIG`，不可重试 |
| 权限/积分不足 | `AUTH`，不可重试，提示至少 2000 积分 |
| Token 无效 | `AUTH`，不可重试 |
| 频率限制 | `RATE_LIMIT`，可重试 |
| 超时 | `DATA`，可重试 |
| 连接失败 | `DATA`，可重试 |
| 服务端 503 | `DATA`，可重试 |

### 5.3 DeepSeek（6）

401 认证失败、402 余额不足、429 限流、500/503 服务失败，以及连续两次非法 JSON。期望为安全 `AgentError`；连续非法内容只进行一次修复且不缓存失败响应。

### 5.4 缓存（2）

缓存读取失败时回退到 fake 模型调用；缓存写入失败时仍返回已校验的 AI 结果。两者都不得让持久化故障覆盖已完成的确定性分析。

所有错误断言同时检查：不包含测试凭据、Authorization、traceback、完整提示词或内部路径。

## 6. AI grounding 与缓存方法

grounding 先按 Pydantic JSON Schema 拒绝多余字段、数量不符和非法枚举，再执行语义验证：

- `source_key` 必须在服务端有限数值快照白名单内；
- `observed_value` 与快照误差不超过 `max(1e-6 × |value|, 1e-6)`；
- `basis_key` 必须是七种服务端观察位之一，价格误差不超过 `max(0.01, 1e-6 × |price|)`；
- 非空 `evidence_key` 也必须存在于服务端快照；
- 规则信号、免责声明、模型名、提示词版本和缓存标志只能由服务端附加。

缓存评测先用一个合法 fake 响应暖缓存，再重复相同 `analysis_id | actual_model | prompt_version` 十次；只有十次都命中且没有新增模型调用才满足 100% 门槛。

## 7. 定时环境与性能限制

报告记录 Python、操作系统、CPU/架构、Pandas、NumPy、`time.perf_counter` 和每个子评测耗时。离线运行禁用网络。耗时受硬件、温度、后台负载和共享 CI 波动影响，因此只披露，不作为 CI 门槛；“缓存命中后小于 2 秒”是产品目标，需在部署环境另做测量，不能由本地 fake 推断。

## 8. 历史回看边界

本离线评测不对未来收益设置 CI 门槛，也不利用五类合成行情制造收益结论。若后续进行历史回看，只可描述性报告未来 5/20 个交易日方向命中、平均收益、最大不利变动与样本数，并必须：

1. 按每个历史截止日做 point-in-time 截断，禁止使用未来行情或复权因子；
2. 覆盖多行业和多市场状态，不只选择最好股票或区间；
3. 披露手续费、滑点、停牌、涨跌停和缺失数据处理；
4. 区分探索、验证和最终测试区间，披露样本选择与多重尝试偏差；
5. 明确历史表现不保证未来结果，收益指标只作教学描述。
