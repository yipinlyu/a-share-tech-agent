# A股智研台用户使用手册

## 1. 首次使用

1. 打开公开 Streamlit 页面；访客无需注册，也无需输入任何 Token 或 API Key。
2. 在侧栏输入 A 股六位代码、完整 Tushare 代码、中文全名或名称片段。
3. 若出现多个候选，依据代码、市场和行业手动选择；系统不会让模型猜股票。
4. 选择 3、6、12、24 或 36 个月回看周期，默认 12 个月，然后点击“开始分析”。
5. 先核对股票代码和“数据最后交易日”，再阅读指标、规则证据、风险与观察位。

页面日线不是实时行情。休市、停牌或数据源延迟时，最后交易日可能早于访问日期。

## 2. 配置与部署

本地开发者需要 Python 3.11。创建 `.venv`、安装项目后，将 `.streamlit/secrets.toml.example` 复制为不会提交 Git 的 `.streamlit/secrets.toml`，填入：

```toml
TUSHARE_TOKEN = "由部署者填写"
DEEPSEEK_API_KEY = "由部署者填写"
DEEPSEEK_BASE_URL = "https://api.deepseek.com"
DEEPSEEK_MODEL = "deepseek-v4-flash"
```

- Tushare 账号至少需要 2000 积分以使用本项目依赖的数据能力；具体接口权限仍以 Tushare 账号状态为准。
- 缺少 Tushare Token 时，股票数据分析不可用；系统只显示配置提示，不生成假数据。
- 缺少 DeepSeek API Key 时，确定性指标和规则评分仍可用，AI 解读与追问禁用。
- Streamlit Community Cloud 的真实值只填在应用 Secrets 后台，不写入仓库、日志、截图或聊天。
- 公开访问者无需输入 Key，页面也不提供凭据输入框。

## 3. 运行分析

### 3.1 选择股票与周期

检索排序依次偏好完整 `ts_code`、六位代码、完整名称、名称包含和模糊名称。多个候选必须由用户确认。周期决定展示窗口；系统在窗口前额外抓取预热数据，计算后才裁剪展示区间。

### 3.2 阅读确定性结果

- 顶部摘要：股票、代码、最后交易日、最新收盘价、五档规则信号和风险等级。
- 主图与标签页：K 线、MA/布林带、MACD、RSI/KDJ、ATR、OBV/成交量。
- 证据区：趋势、动量、量价/波动分组分，正向/负向/冲突证据与数据完整度。
- 观察位：最近 20 日高低点、MA20、布林带或 `close ± ATR` 的观察参考；它们不是止损价或目标价。
- 节点轨迹：展示规划、取数、校验、指标、评分和记忆写入状态，不展示密钥或提示词。

系统使用前复权日线。若预热不足 60 日则停止；60–119 日可继续，但会提示长周期指标可能不稳定。

### 3.3 按需生成 AI 解读

只有点击“生成 AI 解读”才会调用 DeepSeek；页面刷新不会自动扣费。AI 只解释当前结构化快照、规则证据、风险与观察位：

- `rule_signal` 始终是主信号；
- AI 复述与规则不一致时显示 mismatch，不能覆盖规则信号；
- 相同分析、模型和提示词版本可复用已校验缓存；
- JSON 或 grounding 失败只修复一次，仍失败则安全降级且不缓存失败结果。

## 4. 上下文追问

追问只在当前股票分析成功后开放。适合询问指标含义、信号冲突、风险来源、观察位依据或不同周期的解释。每个问题限 1–500 字符。

系统最多保留最近 10 组完整问答；失败回答不加入历史。切换股票或重置分析会创建新线程并清空旧股票对话，避免上下文串线。追问不能要求模型改写规则分数、执行交易、给出个性化仓位或承诺收益。

## 5. 记忆与清理

| 类型 | 内容 | 生命周期 |
|---|---|---|
| 短期当前上下文 | 当前股票、周期、快照、轨迹 | 切股、重置或浏览器会话结束 |
| 短期对话 | 最近 10 组完整问答 | 成组淘汰；切股清空 |
| 短期最近查询/自选 | 最近 20 次查询与会话收藏 | 会话结束清除 |
| 长期分析摘要 | 匿名结构化摘要 | 90 天 |
| 长期 AI 缓存 | 已通过 grounding 的解读 | 30 天 |
| 市场数据缓存 | 最新请求 6 小时；封闭历史请求 30 天 | 到期惰性清理 |
| 股票主数据 | 上市股票检索表 | 24 小时 |

长期 SQLite 不保存身份、API Key、完整聊天或自由文本用户画像。Streamlit Community Cloud 的本地文件系统不是耐久数据库，应用重启或重新部署可能清空缓存。页面“清除本会话记忆”只清当前浏览器会话，不删除其他匿名缓存。

## 6. 常见故障

| 提示/现象 | 原因 | 建议 |
|---|---|---|
| 未配置 Tushare Token | 部署者未设置 Secrets | 联系部署者；访客不要在页面或聊天发送 Token |
| 权限或积分不足 | Tushare 账号能力不足 | 部署者确认至少 2000 积分和接口权限 |
| Token 无效 | 服务端配置错误或已失效 | 部署者在 Secrets 后台更新，勿写入 Git |
| 请求过于频繁 | 数据源限流 | 稍后重试，避免连续点击 |
| 请求区间无数据 | 停牌、未上市、日期或历史长度问题 | 检查股票与日期，换较长周期或稍后重试 |
| 数据不足/质量警告 | 预热不足、缺字段、乱序或异常行情 | 不强行解释；根据提示重选周期或稍后重试 |
| DeepSeek 未配置 | 只配置了数据能力 | 继续使用量化分析，或由部署者补充 Key |
| DeepSeek 余额不足/限流 | 模型账户或服务状态问题 | 稍后重试或联系部署者；量化结果不受影响 |
| AI 内容无法校验 | 模型 JSON 或证据不符合约束 | 以规则信号为准，稍后重新生成 |
| 刷新后历史消失 | Session 或 Cloud 实例重启 | 这是首版轻量记忆限制，不代表数据泄露 |

错误提示中的匿名 `trace_id` 可提供给部署者排查，但不要同时发送任何凭据。系统绝不会用伪造行情静默替代数据源失败。

## 7. 风险声明

**仅供学习研究，不构成投资建议**。

技术指标基于历史日线，存在滞后、噪声、口径、停牌、复权、流动性和市场结构变化风险；规则评分与 AI 解读不是上涨概率、收益预测、交易指令或个性化建议。观察位不等于止损价或目标价，历史回看不保证未来表现。任何投资决定应由用户独立判断并自行承担风险。
